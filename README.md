# Game

This VN is built with stock ren'py with the latest version of the library (8.5.3.26051504+unofficial (Built from AUR))

Python version is 3.14.10

Everything about this repo is mostly stock, and all assets are located in their typical folders.

Fonts: `game/fonts`
Images: `game/images` or `game/gui` depending on what your looking for
Audio: `game/audio`

All assets in these folders belong to their respective owners, and require full atribution to their original author before usage.
